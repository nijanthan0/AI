# AI

Interactive Python, SQL & AI Engineering Learning Studio (Monorepo).

## Structure
- `pylearn-vite/` — Vite + React + TypeScript frontend with CodeMirror, interactive live visualizers, and in-browser WebAssembly execution (Pyodide & SQLite).
- `pylearn-backend/` — FastAPI + SQLAlchemy backend serving structured course content (`content/`), auth, progress sync, billing, and AI mentor APIs.
